# Examples

Prompts to try once the server is installed:

- "Get the price and rating of the Amazon product B09DFCB66S."
- "How many Piloterr credits do I have left?"

Inspect the tools without an AI client:

```sh
export PILOTERR_API_KEY="YOUR_API_KEY"
npx @modelcontextprotocol/inspector npx -y @piloterr/mcp
```
